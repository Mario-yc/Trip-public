及非商业分发本项目。可以用于个人旅行规划和不服务于商业目的的免费教学。

## 必须如何署名

- 保留 `LICENSE`、`NOTICE`、原有版权声明及第三方许可声明。
- 分发源码时，在 README 等显著文档中注明原作者及原项目链接。
- 对用户提供网页或应用时，在易于访问的“关于”、致谢或页脚中显示署名和链接。
- 命令行分发应在帮助、版本信息或随附的显著署名文档中说明来源。
- 说明自己修改了哪些部分，不能冒充原作者，不能暗示原作者为衍生项目背书。

可直接采用以下署名：

> 本项目基于 [Mario-yc](https://github.com/Mario-yc) 的
> [Trip](https://github.com/Mario-yc/Trip-public) 项目开发。
> 仅限非商业使用；完整条件见 LICENSE。

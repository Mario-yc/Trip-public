# Source Transparency

Tags: source, transparency, 来源, 票务, 预约, 官方, fallback, mock, 搜索, 置信度

Use this SOP when explaining POI, tickets, reservations, opening hours, weather, crowding, or guide sources.

- Prefer official sources, then map providers, ticketing/OTA, guide/social, general search, fallback/mock, unknown.
- Do not present fallback or mock data as real availability, official ticket price, or reservation status.
- If no trusted live source is available, tell the user to confirm via official channels.
- Include providerName, confidence, fallbackUsed, failureReason, and userVisibleCaveat when source data is surfaced.
- Provider failure may lower confidence but should not fabricate success.
